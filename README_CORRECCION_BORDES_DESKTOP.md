# Corrección de bordes negros en desktop

Cambios aplicados:
- Fondo del sitio ahora es full-bleed con el mismo estilo visual de la presentación.
- En computador, la presentación escala al ancho del navegador para eliminar los bordes negros laterales.
- El escenario queda centrado horizontalmente y anclado arriba con margen mínimo.
- Los controles Play / Restart / TTS On siguen visibles abajo.
- Mobile mantiene la corrección anterior: presentación visible arriba y controles visibles abajo.

Para probar:
1. Abre `index.html`.
2. En computador, maximiza la ventana: ya no deberían aparecer bordes negros gruesos.
3. En móvil, prueba en modo vertical y presiona Play.
