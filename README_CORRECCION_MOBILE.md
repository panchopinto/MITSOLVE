# Corrección mobile

Cambios aplicados:
- En celulares en vertical, la presentación ya no queda como una miniatura centrada con mucho espacio negro.
- El escenario se agranda, se ancla arriba y se desplaza automáticamente para mostrar el contenido principal.
- Los botones Play / Restart / TTS On quedan fijos y visibles abajo.
- TTS inicia en ON.
- Se agregó una tarjeta de subtítulo/guion visible sobre los controles para que el mensaje se entienda aunque el slide se recorte en formato vertical.
- En computador y en celular horizontal se conserva el diseño original 16:9.

Nota:
En navegadores móviles, el audio TTS necesita un primer clic del usuario. Por eso se debe tocar Play una vez.
